# Earline — turtle-neck alerts that learn you

노트북 · 태블릿 · 휴대폰 · 진동 방석을 하나로 잇는 개인 맞춤 거북목 감지 웹앱 (Diamond Challenge 2027).
앱 화면은 영어, iOS 26 스타일.

**라이브:** https://phaduche.github.io/earline/

## 실행

카메라는 https나 localhost에서만 켜져요.

```bash
cd earline
python3 -m http.server 8000   # 노트북: http://localhost:8000
```

- 휴대폰·아이패드는 위 라이브 주소로 열기. 아이폰은 Safari.
- 아이폰 푸시 알림: Safari 공유 → Add to Home Screen → 그 아이콘으로 열기 (iOS 16.4+)
- 카메라 없이 흐름 테스트: 주소 뒤에 `?sim` → 키보드 `s` 구부정, `t` 머리만 앞으로, `a` 자리비움

## 이번 버전에서 바뀐 것 (1차 고정본 반영)

### 1. 감지 방식: 잘 되던 2단계로 되돌림 (11/6)
실제 카메라로 테스트해 보니, 3단계 학습("머리만 앞으로" 추가)을 넣은 뒤 오히려 바른 자세·구부정까지 구분을 못 했음. "머리만 앞으로"는 바른 자세와 거의 똑같아 보여서 모델이 헷갈렸던 것.

그래서:
- **학습은 다시 2단계**: Sit up straight → Now slump forward. 예전에 잘 되던 모델(특징 10개 + 개인 로지스틱 회귀)을 그대로 복원.
- 예전 3단계 학습은 자동으로 무시돼요 → **각 장소에서 한 번 다시 학습** 필요.
- **"머리만 앞으로" 감지는 설정의 Head-only check (Beta)로 분리, 기본 꺼짐.** 켜면 Dorso 방식(얼굴이 바른 자세 때보다 커지면 = 머리가 화면 쪽으로 옴)으로 추가 감지. 발표 때 시연이 불안하면 꺼둔 채로 쓰면 됨.

시뮬레이션 결과 (몸 흔들림 노이즈 포함):

| 자세 | 거북목 확률 (기본) | Head-only check 켬 |
|---|---|---|
| 바른 자세 | 1% | 1% |
| 구부정 (거북목) | 99% | 100% |
| 반쯤 구부정 | 36–49% | – |
| 뒤로 기대기 | 0% | – |
| 등 그대로, 머리만 앞으로 | 14–21% | 93–99% |

- 거북목·주의 상태일 때 화면에 **"Head 11.0 cm forward"** 처럼 머리가 몇 cm 나왔는지 표시 (MediaPipe 3D 머리 위치 기준 추정값).

### 2. 장소(Places) — 기숙사 / 면학실 / 도서관
고정본의 "의자·장소별 카테고라이징" 아이디어. 장소마다 의자 종류(Desk chair / Stool / Sofa / Floor)와 **따로 학습한 모델**을 가짐 (장소 × 기기 × 화면 방향). 상단 장소 버튼으로 전환, New Place로 추가, 장소별 오늘 바른 자세 %.

### 3. UI
- iOS 26 Liquid Glass: 떠 있는 유리 탭바, 유리 버튼, 시트·액션시트·컨텍스트 메뉴
- 어두운 "스캔" 카드: 정면 실루엣 + 귀·어깨 마커 + 스캔 라인, 상태 링, 카메라 보기 전환
- Face ID식 학습 링 + 결과 화면에 자세별 정확도
- Today 카드: 시간대별 막대그래프(스크린타임 스타일), 최근 5분 그래프
- Devices 탭: 기기 타일 + 장소별 통계
- **Nudge (Dorso 스타일)**: 자세가 나빠질수록 화면 가장자리가 빨갛게 빛나거나(Glow) 화면이 흐려짐(Blur). 설정에서 선택.

### 4. 백그라운드 알림 (11/6)
- 사이트를 열어둔 채 **바탕화면이나 다른 앱**에 있어도, 거북목이면 컴퓨터 알림(문자처럼 오른쪽 위에 뜨는 팝업)이 와요. 탭 제목도 "Turtle neck"으로 깜빡여요.
- 처음에 Posture 화면 위 **Background alerts → Turn On** 한 번 누르면 테스트 알림이 와요. 안 오면 컴퓨터 설정에서 브라우저 알림을 켜야 해요 (Mac: 시스템 설정 → 알림 → Chrome / Windows: 설정 → 알림).
- 알림의 **Snooze 15 min** 버튼으로 15분 동안 알림 끄기.
- 휴대폰은 브라우저 정책상 앱을 나가면 카메라가 멈춰서, 화면을 켜 둔 동안만 감지돼요. 백그라운드 감지는 노트북·데스크톱에서 동작.

### 5. % 표시 1초마다
감지는 1초에 5번 하고, 화면 숫자·상태·머리 cm·그림은 **1초 평균으로 1초마다** 갱신해서 숫자가 덜 흔들려요.

## 동작 원리 (Face-id 코드와 같은 3단계 구조)

| Face-id | Earline |
|---|---|
| Part1 얼굴 100장 수집 | 자세 2개(바른 자세 / 거북목) × 60 샘플 |
| Part2 LBPH 학습 | 로지스틱 회귀(개인 모델), 각 자세 20%로 검증 |
| Part3 confidence > 75 | 거북목 확률 ≥ 90%가 3초 유지되면 알림 (배너 + 소리 + 푸시 + 방석 진동) |

특징 10개: 얼굴 5개(고개 각도, 얼굴 크기, 코 높이, 얼굴 비율, 턱-코) + 어깨 5개(어깨 너비, 목 높이, 코-어깨, 머리/어깨 크기비, 3D 목 각도 CVA).

## 진동 방석

`cushion_esp32.ino` — 센서 없이 진동모터만. 알림 때 BLE로 `[1, 세기]` → 두 번 진동. 웹 블루투스는 노트북·안드로이드 크롬만 지원 (아이폰 Safari 미지원).

## 클라우드 DB

supabase.com → SQL Editor에서 `supabase_setup.sql` 실행 → 앱 Settings → Cloud Sync에 URL·anon key·코드 입력. 같은 코드를 쓰는 기기끼리 모델과 기록 공유.
